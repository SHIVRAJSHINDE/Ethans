Important Python Tuple Methods

Example Tuple: myTuple = ("apple", "banana", "mango")

Note: Tuples are ordered and immutable. Once created, tuple items cannot be directly added, removed, or changed.
Method / Operation Example Output / Result
Access Items
Index [ ] myTuple[0] apple
Description: Returns the item at the specified index.
Negative Index myTuple[-1] mango
Description: Negative indexing accesses items from the end of the tuple.
Slicing
[start:end] myTuple[0:2] ("apple", "banana")
Description: Returns a range of items from the tuple.
[::-1] myTuple[::-1] ("mango", "banana", "apple")
Description: Returns the tuple in reverse order.
Search / Count
index() myTuple.index("banana") 1
Description: Returns the index position of the specified item.
count() myTuple = ("apple", "banana", "apple")
myTuple.count("apple") 		2
Description: Returns how many times the specified item appears in the tuple.
Add / Join
+ tuple1 = ("apple", "banana")
tuple2 = ("mango", "orange")
newTuple = tuple1 + tuple2 		("apple", "banana", "mango", "orange")
Description: Joins two tuples and creates a new tuple.
+= myTuple = ("apple", "banana")
myTuple += ("mango",) 		("apple", "banana", "mango")
Description: Adds another tuple by creating and assigning a new tuple.
Repeat
* ("A", "B") * 2 ("A", "B", "A", "B")
Description: Repeats the tuple the specified number of times.
Check Item
in "banana" in myTuple True
Description: Checks whether an item exists in the tuple.
Length
len() len(myTuple) 3
Description: Returns the total number of items in the tuple.
Convert
list() list(myTuple) ["apple", "banana", "mango"]
Description: Converts a tuple into a list.
tuple() tuple(["apple", "banana", "mango"]) ("apple", "banana", "mango")
Description: Converts another iterable, such as a list, into a tuple.
Copy
Assignment newTuple = myTuple ("apple", "banana", "mango")
Description: Assigns the tuple to another variable. Since tuples are immutable, a separate copy method is generally not required.
