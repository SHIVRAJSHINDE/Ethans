Important Python Dictionary Methods

Example Dictionary: myDict = {"name": "John", "age": 25, "city": "Pune"}

Note: Dictionaries store data in key : value pairs. Keys must be unique.
Method / Operation Example Output / Result
Access Items
[key] myDict["name"] John
Description: Returns the value of the specified key.
get() myDict.get("age") 25
Description: Returns the value of the specified key. Returns None if the key does not exist.
Add / Update Items
[key] = value myDict["country"] = "India" {"name": "John", "age": 25, "city": "Pune", "country": "India"}
Description: Adds a new key-value pair to the dictionary.
[key] = value myDict["age"] = 30 {"name": "John", "age": 30, "city": "Pune"}
Description: Changes the value if the key already exists.
update() myDict.update({"age": 30, "country": "India"}) {"name": "John", "age": 30, "city": "Pune", "country": "India"}
Description: Adds new items or updates existing key-value pairs.
Remove Items
pop() myDict.pop("age") {"name": "John", "city": "Pune"}
Description: Removes the specified key and returns its value.
popitem() myDict.popitem() Removes the last inserted key-value pair
Description: Removes and returns the last inserted key-value pair.
del del myDict["age"] {"name": "John", "city": "Pune"}
Description: Deletes the specified key-value pair.
clear() myDict.clear() {}
Description: Removes all items from the dictionary.
Keys / Values / Items
keys() myDict.keys() dict_keys(['name', 'age', 'city'])
Description: Returns all keys from the dictionary.
values() myDict.values() dict_values(['John', 25, 'Pune'])
Description: Returns all values from the dictionary.
items() myDict.items() dict_items([('name','John'), ('age',25), ('city','Pune')])
Description: Returns all key-value pairs as tuple-like pairs.
Check Item
in "name" in myDict True
Description: Checks whether the specified key exists in the dictionary.
Length
len() len(myDict) 3
Description: Returns the number of key-value pairs in the dictionary.
Copy
copy() newDict = myDict.copy() {"name": "John", "age": 25, "city": "Pune"}
Description: Creates a shallow copy of the dictionary.
Create Dictionary
dict() dict(name="John", age=25) {"name": "John", "age": 25}
Description: Creates a new dictionary.
fromkeys() keys = ("name", "age", "city")
dict.fromkeys(keys, "Unknown") 		{"name": "Unknown", "age": "Unknown", "city": "Unknown"}
Description: Creates a dictionary using specified keys with the same default value.
Default Value
setdefault() myDict.setdefault("country", "India") {"name": "John", "age": 25, "city": "Pune", "country": "India"}
Description: Returns the value if the key exists. If not, it inserts the key with the specified default value.
