Important Python String Functions

Important: Python strings are immutable. String methods return a new string and do not modify the original string.
Method Example Output Description
Case Conversion
upper() txt = "Hello my friends"
x = txt.upper() 		HELLO MY FRIENDS Converts all characters to uppercase.
lower() txt = "Hello my FRIENDS"
x = txt.lower() 		hello my friends Converts all characters to lowercase.
Replace / Join / Split
replace() txt = "I like bananas"
x = txt.replace("bananas", "apples") 		I like apples Replaces a specified value with another specified value.
join() myTuple = ("John", "Peter", "Vicky")
x = "#".join(myTuple) 		John#Peter#Vicky Joins the elements of an iterable using the specified string as the separator.
split() txt = "welcome to the jungle"
x = txt.split() 		['welcome', 'to', 'the', 'jungle'] Splits a string at the specified separator and returns a list.
Search / Count
count() txt = "I love apples, apple are my favorite fruit"
x = txt.count("apple") 		2 Returns the number of times a specified value occurs in the string.
startswith() txt = "Hello, welcome to my world."
x = txt.startswith("Hello") 		True Returns True if the string starts with the specified value.
endswith() txt = "Hello, welcome to my world."
x = txt.endswith(".") 		True Returns True if the string ends with the specified value.
find() txt = "Hello, welcome to my world."
x = txt.find("welcome") 		7 Returns the index position where the specified value is first found. Returns -1 if not found.
index() txt = "Hello, welcome to my world."
x = txt.index("welcome") 		7 Returns the index position where the specified value is first found. Raises an error if not found.
String Validation
isnumeric() txt = "565543"
x = txt.isnumeric() 		True Returns True if all characters in the string are numeric.
isdigit() txt = "50800"
x = txt.isdigit() 		True Returns True if all characters in the string are digits.
isalpha() txt = "Company"
x = txt.isalpha() 		True Returns True if all characters in the string are alphabetic.
isalnum() txt = "Company12"
x = txt.isalnum() 		True Returns True if all characters are letters or numbers.
