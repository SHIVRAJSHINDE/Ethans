Important Python Set Methods

Example Set: mySet = {"apple", "banana", "mango"}

Note: Sets are unordered and do not allow duplicate values.
Method Example Output / Result
Add Items
add() mySet.add("orange") {"apple", "banana", "mango", "orange"}
Description: Adds one item to the set.
update() mySet.update(["orange", "grapes"]) {"apple", "banana", "mango", "orange", "grapes"}
Description: Adds multiple items to the set.
Remove Items
remove() mySet.remove("banana") {"apple", "mango"}
Description: Removes the specified item. Gives an error if the item does not exist.
discard() mySet.discard("banana") {"apple", "mango"}
Description: Removes the specified item. Does not give an error if the item does not exist.
pop() mySet.pop() Removes an arbitrary item
Description: Removes and returns an arbitrary item from the set.
clear() mySet.clear() set()
Description: Removes all items from the set.
Set Operations
union() set1 = {1, 2, 3}
set2 = {3, 4, 5}
set1.union(set2) 		{1, 2, 3, 4, 5}
Description: Returns all unique items from both sets.
intersection() set1 = {1, 2, 3}
set2 = {2, 3, 4}
set1.intersection(set2) 		{2, 3}
Description: Returns the common items from both sets.
difference() set1 = {1, 2, 3}
set2 = {2, 3, 4}
set1.difference(set2) 		{1}
Description: Returns items present in set1 but not in set2.
symmetric_difference() set1 = {1, 2, 3}
set2 = {2, 3, 4}
set1.symmetric_difference(set2) 		{1, 4}
Description: Returns items that are not common between both sets.
Copy
copy() newSet = mySet.copy() {"apple", "banana", "mango"}
Description: Creates a shallow copy of the set.
